## 🗺️ Study Roadmap

The checklist below tracks the planned learning path. Mark an item as complete
only after its implementation, notes, or diagrams have been added to the
repository.

### 1️⃣ Fundamentals of Low-Level Design & OOP

✅ Introduction to LLD: LLD vs. HLD vs. DSA
- [ ] OOP pillars: abstraction, encapsulation, inheritance, and polymorphism
- [ ] Real-world OOP examples and class design
- [ ] UML diagrams: class, sequence, activity, and use-case diagrams
- [ ] UML dynamic relationships and notation details
- [ ] SOLID: Single Responsibility Principle (SRP)
- [ ] SOLID: Open/Closed Principle (OCP)
- [ ] SOLID: Liskov Substitution Principle (LSP)
- [ ] SOLID: Interface Segregation Principle (ISP)
- [ ] SOLID: Dependency Inversion Principle (DIP)

### 2️⃣ Creational Design Patterns

- [ ] Factory patterns: Simple Factory, Factory Method, and Abstract Factory
- [ ] Singleton: thread-safe, lazy, and eager initialization
- [ ] Builder: constructing complex objects step-by-step
- [ ] Prototype: object cloning and prototype registry

### 3️⃣ Structural Design Patterns

- [ ] Decorator: adding behaviors dynamically to objects
- [ ] Observer: event handling, notifications, and pub-sub mechanisms
- [ ] Composite: hierarchical tree structures and file systems
- [ ] Adapter: interface conversion and third-party integrations
- [ ] Facade: simplifying complex subsystems
- [ ] Proxy: access control, caching, and lazy loading
- [ ] Flyweight: memory optimization and shared state

### 4️⃣ Behavioral Design Patterns

- [ ] Strategy: interchangeable algorithm implementations
- [ ] Command: requests, undo/redo, and smart-home automation
- [ ] Chain of Responsibility: request pipelines and cash dispensers
- [ ] State: state-machine logic and vending machines
- [ ] Mediator: loosely coupled communication and chat rooms
- [ ] Iterator: traversing collection elements
- [ ] Memento: saving and restoring object state
- [ ] Template Method: defining algorithm skeletons
- [ ] Visitor: operations over object structures and double dispatch

### 5️⃣ Practical LLD Projects & Machine Coding

- [ ] Food delivery application
- [ ] Quick-commerce and inventory management system
- [ ] Parking lot system
- [ ] Elevator or lift management system
- [ ] Movie ticket booking system
- [ ] Expense-sharing application
- [ ] Snake and Ladder game
- [ ] Vending machine
- [ ] Smart home automation

### 6️⃣ Anti-Patterns & Best Practices

- [ ] Null Object Pattern
- [ ] Code refactoring and code smells
- [ ] Machine-coding round strategy and edge-case handling
